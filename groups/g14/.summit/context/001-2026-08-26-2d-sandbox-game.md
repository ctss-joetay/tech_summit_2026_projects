Built a 2D sandbox game featuring a canvas-based grid world that players can paint with different block types (grass, dirt, stone, wood) using mouse drag actions, plus a controllable player character with basic gravity and collision physics. Added Save/Load/Clear buttons backed by the Summit runtime so worlds persist across reloads. The implementation favors simple custom physics and grid logic over external libraries for a lightweight sandbox experience.
