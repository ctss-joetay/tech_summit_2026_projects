Built a task tracker app with a form to add tasks, persistence via Summit.save so tasks survive reloads, a sticky top banner that cycles through pending tasks as reminders, checkboxes to mark tasks complete which moves them into a retired/completed list with strikethrough styling, and a delete button to remove tasks entirely.
