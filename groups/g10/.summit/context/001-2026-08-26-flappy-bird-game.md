Built a beginner-friendly canvas-based Flappy Bird game with gravity physics, click/space-to-flap controls, scrolling pipes with collision detection, and scoring. High score persistence and leaderboard submission were wired up using Summit.save/load and Summit.submitScore. Code was commented for clarity given the beginner request.
